# NPTV25 — общий чат

## Что сделано

- Один общий чат `/chat/`.
- Слева список активных пользователей через Redis presence.
- Администраторы отмечаются бейджем `АДМИН`.
- Сообщения приходят в реальном времени через Django Channels/WebSocket.
- История последних 100 сообщений хранится в базе данных.
- Сообщения пользователя выровнены справа, остальные — слева.
- Область сообщений имеет собственную прокрутку; поле отправки закреплено снизу.
- WebSocket автоматически переподключается при разрыве соединения.
- Администратор (`is_staff` или `is_superuser`) может удалять сообщения прямо из общего чата.
- Удаление сообщения синхронно отображается у всех подключённых пользователей.

## Render

Start Command:

```bash
daphne -b 0.0.0.0 -p $PORT myproject.asgi:application
```

Environment Variable:

```text
REDIS_URL=redis://<internal-render-redis>:6379
```

Для production желательно использовать PostgreSQL через `DATABASE_URL`.

## Администратор

Пользователь считается администратором, если у него `is_staff=True` или `is_superuser=True`.

Создать superuser локально:

```bash
python manage.py createsuperuser
```

Либо открыть Django Admin и включить пользователю `Staff status`.
